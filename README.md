# Proyecto Área de Figuras Geométricas

## Descripción

Este proyecto consiste en una página web desarrollada con React que permite calcular el área de tres figuras geométricas: triángulo, rectángulo y cuadrado.

El usuario debe ingresar los valores correspondientes y presionar el botón para obtener el resultado.

## Tecnologías utilizadas

- React
- JavaScript
- Bootstrap
- HTML
- CSS
- Vite

## Funcionalidades

### Triángulo

Permite ingresar la base y la altura para calcular el área.

Fórmula:

Área = (Base × Altura) / 2

### Rectángulo

Permite ingresar la base y la altura.

Fórmula:

Área = Base × Altura

### Cuadrado

Permite ingresar los lados.

Fórmula:

Área = Lado × Lado

## React Hooks

El proyecto utiliza el Hook `useState` para almacenar los valores ingresados por el usuario y mostrar los resultados de los cálculos.

## Estructura

- `index.html`: estructura principal de la página.
- `index.jsx`: punto de entrada de React.
- `figuras.jsx`: contiene los componentes y cálculos de las figuras.
- `style.css`: estilos personalizados.
- `README.md`: descripción del proyecto.
